## ADDED Requirements

### Requirement: Import entry point
The system SHALL offer an "Import project" action on the dashboard next to the "New project" tile that starts the import flow, and the project settings SHALL offer an "Export" action.

#### Scenario: Start an import
- **WHEN** the user chooses "Import project" on the dashboard
- **THEN** a file picker opens and, after a valid selection, the import preview is shown
